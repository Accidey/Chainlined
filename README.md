# ChainMailed

> A vanilla-styled rework of chainmail armor, ported to NeoForge.
> 一款原版风格、对锁链甲进行全面重做的模组，已移植至 NeoForge。

## English

### About

**ChainMailed** is a Minecraft **NeoForge** mod for **Minecraft 1.21.1** that gives chainmail armor the rework it deserves. It introduces a **Chainmail Lining** system and the all-new **Impact Resistance** attribute while keeping the vanilla visual style.

### Features

- **Chainmail Lining** — Line any armor piece with chainmail to gain extra defense and Impact Resistance.
- **Impact Resistance** — Reduces incoming melee, player and generic damage by a fixed amount, always leaving at least 1 point of damage.
- **Full Set Bonus** — A fully lined set ignores player sweeping attacks.
- **Crafting Recipes** — Craft vanilla chainmail armor from iron nuggets and chains.
- **New Advancement & Sound** — The "Chainmailed!" advancement and a dedicated chainmail block sound.
- **Configurable** — Sound, Impact Resistance values, per-slot armor values and the lining blacklist are all configurable.
- **In-Game Commands** — `/chainmailed blacklist add|remove <item>`.

This is a port of the original *ChainMailed* mod to the NeoForge platform. We would like to express our sincere gratitude to the original authors for their outstanding work.

### Requirements

- Minecraft **1.21.1**
- **NeoForge** 21.1.249 or later
- Java **21**

### Installation

1. Install NeoForge for Minecraft 1.21.1.
2. Put the mod JAR into the `mods` folder.
3. Launch the game.

## 中文

### 关于

**ChainMailed** 是一个基于 **Minecraft 1.21.1** 的 **NeoForge** 模组，为锁链甲带来一次应有的重做。模组在保留原版视觉风格的前提下，引入了**锁链内衬**系统与全新的**冲击抗性**属性。

### 特性

- **锁链内衬** — 可为任意护甲加装锁链内衬，获得额外防御与冲击抗性。
- **冲击抗性** — 按固定数值减免近战、玩家与通用伤害，且至少保留 1 点伤害。
- **全套加成** — 全套加衬护甲无视玩家的横扫攻击。
- **合成配方** — 可使用铁粒与锁链合成原版锁链甲。
- **新进度与音效** — 新增「锁链内衬！」进度与专属的锁链甲格挡音效。
- **可配置** — 音效、冲击抗性数值、各部位护甲值与内衬黑名单均可配置。
- **游戏内指令** — `/chainmailed blacklist add|remove <物品>`。

### 原作者

- **AstianBk**
- **SangreBK**

原版 *ChainMailed* 项目由上述作者为 **Minecraft 1.20.1（Forge）** 创作。

### 运行环境
