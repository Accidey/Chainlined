# Chainlined

> A vanilla-styled rework of chainmail armor for NeoForge.
> 一款原版风格、对锁链甲进行全面重做的 NeoForge 模组。

---

## English

### About

**Chainlined** is a Minecraft **NeoForge** mod for **Minecraft 1.21.1** that gives chainmail armor the rework it deserves. It introduces a **Chainmail Lining** system that grants extra defense to any armor piece, while keeping the vanilla visual style.

### Features

- **Chainmail Lining (Anvil)** — Put an armor piece in the left anvil slot and a chainmail piece for the same slot in the right slot, then take out the lined armor. The right-slot chainmail is consumed and a small amount of experience is paid.
- **Lining Inheritance** — When a lined armor piece is used to craft an upgraded armor piece of the same slot on a crafting table, the lining is preserved on the result.
- **Crafting Recipes** — Craft vanilla chainmail armor from iron nuggets and chains.
- **New Advancements** — "Chainmailed!" and "Lined in Steel".
- **Configurable** — Per-slot armor values, the anvil experience cost and the lining blacklist are all configurable.
- **In-Game Commands** — `/chainlined blacklist add|remove <item>`.

### Author

- **Accidey**

### Requirements

- Minecraft **1.21.1**
- **NeoForge** 21.1.249 or later
- Java **21**

### Installation

1. Install NeoForge for Minecraft 1.21.1.
2. Put the mod JAR into the `mods` folder.
3. Launch the game.

## 中文

### 关于

**Chainlined** 是一个基于 **Minecraft 1.21.1** 的 **NeoForge** 模组，为锁链甲带来一次应有的重做。模组在保留原版视觉风格的前提下，引入了**锁链内衬**系统，可为任意护甲附加额外防御。

### 特性

- **锁链内衬（铁砧）** — 在铁砧左槽放入任意护甲、右槽放入同部位的锁链甲，即可取出加衬护甲。右槽锁链甲会被消耗，并支付少量经验。
- **内衬继承** — 用加衬护甲在工作台合成同部位的升级护甲时，内衬会保留在合成结果上。
- **合成配方** — 可使用铁粒与锁链合成原版锁链甲。
- **新进度** — 新增「锁链内衬！」与「钢甲衬链」进度。
- **可配置** — 各部位护甲值、铁砧经验费用与内衬黑名单均可配置。
- **游戏内指令** — `/chainlined blacklist add|remove <物品>`。

### 作者

- **Accidey**

### 运行环境

- Minecraft **1.21.1**
- **NeoForge** 21.1.249 及以上版本
- Java **21**

### 安装方法

1. 安装对应 Minecraft 1.21.1 的 NeoForge。
2. 将模组 JAR 放入 `mods` 文件夹。
3. 启动游戏即可体验。
